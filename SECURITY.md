# Security

## Status

This code has had an internal review ([docs/audit.md](docs/audit.md)) and no
external audit. Read [the status section of the README](README.md#status) before
running it anywhere that holds value.

## Reporting

Report vulnerabilities privately through GitHub's "Report a vulnerability"
button on the Security tab, not as a public issue.

Please include the affected component (`src/`, `node/`, `offchain/`), a
reproduction, and the impact you believe it has. A first response should come
within a few days.
